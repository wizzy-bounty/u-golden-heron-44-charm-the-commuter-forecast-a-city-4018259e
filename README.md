## The entry

One line of weather forecast (136 characters) for Upwick, a city that
does not exist, where the rain falls upwards:

> Today in Upwick: rain falling upwards, so hold your umbrella underneath you — the 8:15 bus is on time, your shoes are soaked from below.

The line keeps the rhythm of a real broadcast forecast ("Today in ..."),
names the invented city, makes its impossible weather the whole point,
and turns it on the commuter's own morning: the umbrella goes
underneath, the bus is on time for once, and the shoes still end up
soaked — from below.

## How to run

Python 3, standard library only, no network, deterministic:

```sh
python3 main.py
```

It writes the forecast to `/output/entry.txt` (override with the
`MAKEFUN_OUTPUT` environment variable for local testing).
